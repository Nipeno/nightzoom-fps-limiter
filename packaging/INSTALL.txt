WHAT'S IN THIS ZIP
------------------------------------------------------------
  dxgi.dll            <- ReShade (official). The thing that
                         loads add-ons. ONLY needed if you do
                         NOT already have ReShade.
  NightZoom.addon64   <- The 60 FPS limiter itself.
  INSTALL.txt         <- This file.
  ReShade-LICENSE.txt <- License for the bundled ReShade.
  LICENSE.txt         <- License for NightZoom (GPLv3).


WHY 60 FPS?
------------------------------------------------------------
GTA's physics is tied to your frame rate - higher FPS can
change how the car behaves. On a racing server that's unfair:
people on stronger PCs would get an edge. Capping everyone to
60 FPS keeps the physics consistent so nobody has an advantage.


WHERE THINGS GO  (FiveM)
------------------------------------------------------------
Everything goes in your FiveM "plugins" folder:

  C:\Users\<YOU>\AppData\Local\FiveM\FiveM.app\plugins\

Tip: press Win+R, paste this, press Enter:
  %localappdata%\FiveM\FiveM.app\plugins


PICK ONE OF THE TWO OPTIONS BELOW
------------------------------------------------------------

OPTION A - You ALREADY have ReShade
(e.g. you run NVE, QuantV, or another graphics pack)
  1. Copy ONLY  NightZoom.addon64  into the plugins folder.
  2. DELETE the  dxgi.dll  from this zip - do NOT copy it.
     (You already have a ReShade; two will conflict.)

OPTION B - You do NOT have ReShade yet
  1. Copy ALL files from this zip into the plugins folder.
     NOTE: copy the FILES (dxgi.dll, NightZoom.addon64, ...),
     NOT a folder. If Windows "Extract All" made a folder, open
     it and copy what's INSIDE - the plugins folder should
     contain dxgi.dll directly, not a sub-folder.


THEN
------------------------------------------------------------
  1. Start FiveM / join the server.
  2. Press  Home  to open the ReShade menu.
  3. Find the  "NightZoom FPS Limiter"  window.
  4. Tick  "Limit to 60 FPS".  Done - your choice is saved.


HOW TO USE
------------------------------------------------------------
  - Press  Home  to open or close the ReShade menu in-game.
    (Home is the default key - you can change it later in
     ReShade's Settings. The very first time, ReShade shows a
     welcome / tutorial pop-up - just click "Continue" or
     "Skip Tutorial" to get past it.)

  - In the menu, find the  "NightZoom FPS Limiter"  window.
    If you don't see it, look at the top tabs - make sure
    you're on the "Home" / add-ons view, not "Settings".

  - Tick   "Limit to 60 FPS"   -> your game is now capped at 60.
    Untick it                  -> the cap is removed instantly.

  - Your choice is saved automatically and stays set the next
    time you launch.

  - Press  Home  again to close the menu and keep playing.


IMPORTANT: FIRST LAUNCH - "ReShade was blocked"
------------------------------------------------------------
FiveM blocks modern ReShade by default. The FIRST time, you may
see red text in the FiveM console like:

  Blocked load of ReShade version 5 or higher ...
  If you want to force it to load anyway, add the following
  section to <path>\CitizenFX.ini:
     [Addons]
     ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug...

To allow ReShade (one-time fix):
  1. Fully close FiveM.
  2. Open the file it named:  CitizenFX.ini
     (it sits in your FiveM.app folder - the console message
      shows the exact full path).
  3. Add the two lines EXACTLY as the console showed YOU:

        [Addons]
        ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug that will lead to game crashes

     IMPORTANT: the ID (xxxxxxxx) is UNIQUE to your PC. Copy the
     line straight from your own FiveM console - do not use the
     example above.
  4. Save the file and start FiveM again.

(If you already use ReShade with FiveM, e.g. via NVE/QuantV,
 you've likely done this already and can skip it.)


HOW TO UNINSTALL
------------------------------------------------------------
  1. Close FiveM.
  2. Open the plugins folder:
       %localappdata%\FiveM\FiveM.app\plugins
  3. Delete  NightZoom.addon64.
  4. Only if you installed the bundled ReShade just for this
     (Option B) and want ReShade gone too, also delete  dxgi.dll.
     If your graphics pack (NVE/QuantV) put ReShade there,
     LEAVE dxgi.dll alone.
