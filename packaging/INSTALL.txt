==========================================================
  NightZoom FPS Limiter  -  Install Guide
  Locks your game to a smooth 60 FPS.
  Made by Nipeno  -  Discord: https://discord.gg/nightzoom
==========================================================

This zip has EVERYTHING: the 60 FPS limiter AND ReShade (the
thing that runs it). If you already have ReShade working in
FiveM, you'll skip a couple of steps - the guide says where.


WHAT'S IN THIS ZIP
------------------------------------------------------------
  NZ-FPS-Limiter.addon64 <- The 60 FPS limiter.
  dxgi.dll               <- ReShade itself (official). Only
                            needed if you do NOT already have it.
  Enable-ReShade.bat     <- One click: "allow ReShade in FiveM".
  INSTALL.txt            <- This file.
  ReShade-LICENSE.txt    <- License for the bundled ReShade.
  LICENSE.txt            <- License for NightZoom FPS Limiter.


INSTALL  (FiveM)
------------------------------------------------------------

STEP 1 - Open your FiveM "plugins" folder.
   Press  Win+R , paste this line, press Enter:

       %localappdata%\FiveM\FiveM.app\plugins

   A folder window opens. Leave it open.

   Error, or nothing opened? Then FiveM isn't in the default
   spot. Open YOUR FiveM install folder instead (the one that
   has FiveM.exe) and go into the  FiveM.app\plugins  inside it.

STEP 2 - Copy  NZ-FPS-Limiter.addon64  into that folder.

   >>> ALREADY HAVE RESHADE WORKING IN FIVEM? <<<
   (e.g. you run NVE, QuantV, or another graphics pack, and the
    ReShade menu already opens in game)
   Then you're done setting up - SKIP to STEP 5. Do NOT copy the
   dxgi.dll: you already have ReShade, and two copies conflict.

STEP 3 - Copy  dxgi.dll  into the plugins folder too.
   (This file IS ReShade. Only do this if you do NOT already
    have ReShade.)

   Copy the FILES themselves, not a folder. If extracting made a
   folder, open it and copy what's INSIDE. When done, the plugins
   folder should show  dxgi.dll  directly, not a sub-folder.

STEP 4 - Allow ReShade in FiveM (one time).
   In the plugins folder, double-click:

       Enable-ReShade.bat

   It sets everything up by itself. Press a key to close it.
   - Blue "Windows protected your PC" box? Click "More info" ->
     "Run anyway". (Open source - read it in Notepad first if you
     like.)
   - Says it couldn't find FiveM? See "IF THE .BAT CAN'T FIND
     FIVEM" below.

STEP 5 - Start FiveM, then turn the limiter ON.
   Press  Home  to open the ReShade menu. (Some setups - like
   NVE - use  Insert  instead; if Home does nothing, try Insert.)
   First time, ReShade shows a tutorial pop-up: click "Continue"
   or "Skip Tutorial".
   Find the  "NightZoom FPS Limiter"  window and tick
   "Limit to 60 FPS".

   DONE. Your choice is saved for next time.


WHY 60 FPS?
------------------------------------------------------------
GTA's physics is tied to your frame rate - higher FPS can change
how the car behaves. On a racing server that's unfair: people on
stronger PCs would get an edge. Capping everyone to 60 FPS keeps
the physics consistent so nobody has an advantage.


STILL DON'T SEE THE WINDOW?  (your ReShade is too old)
------------------------------------------------------------
If you skipped to STEP 5 using your own ReShade but the
"NightZoom FPS Limiter" window never shows up, that ReShade is
probably too old to load it (check ReShade.log for "requested
API version ... is not supported").

Fix: do STEP 3 - copy THIS zip's  dxgi.dll  into your plugins
folder, replacing the old one - then start FiveM again. It's the
latest official ReShade and still runs NVE / QuantV fine.


IF THE .BAT CAN'T FIND FIVEM  (manual allow)
------------------------------------------------------------
Only needed if Enable-ReShade.bat couldn't locate FiveM. The
first time you launch with ReShade, FiveM's console shows red
text like:

  Blocked load of ReShade version 5 or higher ...
  add the following section to <path>\CitizenFX.ini:
     [Addons]
     ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug...

  1. Fully close FiveM.
  2. Open the file it named:  CitizenFX.ini  (in your FiveM.app
     folder - the console shows the exact full path).
  3. Add the two lines EXACTLY as YOUR console showed them:

        [Addons]
        ReShade5=ID:xxxxxxxx acknowledged that ReShade 5.x has a bug that will lead to game crashes

     The ID (xxxxxxxx) is UNIQUE to your PC - copy it from your
     own console, not from this example.
  4. Save and start FiveM again.


HOW TO USE
------------------------------------------------------------
  - Press  Home  (or  Insert) to open/close the ReShade menu.
  - In the  "NightZoom FPS Limiter"  window:
       tick   "Limit to 60 FPS"  -> capped at 60.
       untick it                 -> cap removed instantly.
  - Your choice is saved and stays set next launch.
  - Don't see the window? Make sure you're on the "Home" /
    add-ons tab, not "Settings".


HOW TO UNINSTALL
------------------------------------------------------------
  1. Close FiveM.
  2. Open  %localappdata%\FiveM\FiveM.app\plugins
  3. Delete  NZ-FPS-Limiter.addon64.
  4. Only if you added this zip's dxgi.dll JUST for this and want
     ReShade gone too, also delete  dxgi.dll. If a graphics pack
     (NVE/QuantV) put ReShade there, LEAVE dxgi.dll alone.
